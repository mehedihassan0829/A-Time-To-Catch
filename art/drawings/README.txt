All the drawings from the game as PNG images (same folders as the pixilart folder).

Each image is shown at the size it appears in the game (every art pixel = 4x4 screen pixels),
except the whole-map pictures, which are at 1 pixel per art pixel so they're not enormous.
Files ending in _N_frames are animations: the frames are side by side, left to right.

The .pixil versions (for editing on pixilart.com) are in the pixilart folder.
Building outlines are based on OpenStreetMap: Map data (c) OpenStreetMap contributors.
