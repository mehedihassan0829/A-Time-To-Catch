# A-Time-To-Catch

A top-down game set on Queens Road, Bristol, drawn at a three-quarter angle.

In 2026, a detective with the ability to witness fragments of the past is called to investigate the latest murder attributed to the Bristol Pusher, a killer who has remained dormant for eleven years. Investigating the final days of victim John, the detective interviews three people from his life: his arcade coworker, a close friend and a local journalist, before speaking to his university professor, Dr Peter Usher. Through objects left behind by John, the detective reconstructs his movements and uncovers a hidden investigation into the Bristol Pusher. An old arcade token reveals that John's father was Jack, the killer's first victim in 1999. As the detective uncovers the original arcade records, he finally discovers the identity of the murderer. But when he reaches Temple Meads, two trains are about to depart, and he must make a decision that could determine whether the Bristol Pusher escapes forever.

## Run it

```
pip install -r requirements.txt
python topdown.py
```

| Key | |
|---|---|
| WASD / arrows | move |
| Shift | run |
| Tab | switch character |
| M | switch map (Queens Road / Town) |
| F1 | show hitboxes |
| F3 | show FPS |
