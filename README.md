# A-Time-To-Catch

A top-down game set on Queens Road, Bristol, drawn at a three-quarter angle.

## Run it

```
pip install -r requirements.txt
python topdown.py
```

| Key | |
|---|---|
| WASD / arrows | move |
| Shift | run |
| Tab | switch character |
| M | switch map (Queens Road / Town) |
| F1 | show hitboxes |
| F3 | show FPS |
